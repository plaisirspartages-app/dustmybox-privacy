Politique de confidentialité — DustMyBox

Dernière mise à jour : septembre 2026

1. Qui sommes-nous ?

DustMyBox est une application mobile Android développée par Lucie Marty.
Contact : dustmybox.app@gmail.com

2. Quelles données sont utilisées ?

DustMyBox accède uniquement aux métadonnées de votre boîte mail :

  • Adresse e-mail de l'expéditeur
  • Taille estimée du message
  • Date de réception

Le contenu de vos messages (corps, pièces jointes, objet) n'est jamais lu, téléchargé ni transmis.

3. Où sont stockées vos données ?

Toutes les données restent sur votre appareil :

  • Cache temporaire (2 heures) : métadonnées des mails pour accélérer les chargements suivants
  • Stockage permanent local : statistiques, défis, mails et expéditeurs protégés, compte(s) IMAP

Aucune donnée n'est envoyée à un serveur externe.

4. Connexion Google (Gmail)

Pour les comptes Gmail, DustMyBox utilise l'API Gmail de Google via OAuth 2.0. L'application demande la permission GMAIL_MODIFY pour :

  • Lire les métadonnées des mails de votre boîte de réception
  • Déplacer les mails sélectionnés vers la corbeille

Vous pouvez révoquer cet accès à tout moment depuis votre compte Google → Sécurité → Applications tierces.
DustMyBox ne stocke jamais votre mot de passe Google.

5. Connexion IMAP (autres fournisseurs)

Pour les comptes non-Gmail, vos identifiants (adresse e-mail et mot de passe d'application) sont stockés localement dans les préférences sécurisées de votre téléphone. Ils ne sont jamais transmis à un tiers.

6. Publicités

DustMyBox affiche des publicités via Google AdMob. AdMob peut collecter des identifiants publicitaires pour personnaliser les annonces, conformément à la politique de confidentialité de Google. Vous pouvez limiter la personnalisation des annonces dans les paramètres de votre appareil.

7. Vos droits (RGPD)

  • Accès : toutes vos données sont consultables directement dans l'application
  • Suppression : désinstaller l'application supprime toutes les données locales
  • Opposition : vous pouvez révoquer l'accès Gmail depuis votre compte Google à tout moment

Pour toute demande : dustmybox.app@gmail.com

8. Modifications

Toute modification de cette politique sera indiquée par la mise à jour de la date en haut de cette page.
